# apps/web

Next.js app for Glassbox. The public site is https://glassbox-inky.vercel.app. `pnpm --filter web dev` serves the same app at http://localhost:3000.

The page posts to `/api/audit`. The route accepts a NEAR account id or JSON text and does not read local files. The preferred production limiter is Upstash Redis: set both `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` (or the `KV_REST_API_URL` / `KV_REST_API_TOKEN` pair). When that store is present, admission uses the shared budget of 10 audits per minute and 2 at a time for the whole deployment, including when the demo flag is also set. When `GLASSBOX_AUDIT_TOKEN` is set and no shared store is configured, callers must send header `x-glassbox-audit-token`. `GLASSBOX_PUBLIC_DEMO=1` is process-local demo mode, with a cap of 10 per minute in that one process. That cap is not shared across instances. A POST to the public demo on 2026-11-10 returned `x-glassbox-rate-limit-scope: shared`, so that deployment was on the shared budget. With none of those settings, the route returns 403 and does not call RPC. Local `pnpm --filter web dev` does that until you set one. Paste an account (the hint reads `.testnet` / `.near`) or a JSON document. A pasted JSON report compares values in that text. It is not a fresh chain read, except that a quote in the text is verified as those bytes.

The hero shows the form and the proof strip from `data/proof-strip.json`, a saved seven-account snapshot (`generatedAt` `2026-11-05T10:21:06.337Z`). Rebuild that file from the repo root with `node packages/cli/bin/glassbox.js index` (this replaces the snapshot with three local fixtures) or, for the seven accounts, `node packages/cli/bin/glassbox.js index --live`. Smoke and MPC targets are not in that file.
